RPAD website mockup in WordPress Playground

Opens a temporary WordPress site in your browser with every mockup page built from standard Elementor blocks (Astra theme + Elementor + Elementor Header & Footer Builder). All menus and links are clickable.

Open the clickable site »
Good to know
• It takes about a minute to set up the first time.
• It's a test sandbox: nothing is saved, and it resets when the tab is closed or reloaded.
• To edit a page: open it, then click Edit with Elementor in the top black bar.
• Forms and the tax-year dropdown are look-alike placeholders; the homepage slideshow and countdown are frozen (those are Elementor Pro / Formidable on the City site).

For DIT: all pages as Elementor template files (.zip) – Elementor → Templates → Saved Templates → Import Templates.
